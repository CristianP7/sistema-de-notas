# 📝 Sistema de Gestión de Notas

Proyecto desarrollado como práctica de programación en JavaScript.

## 📌 Descripción

Este sistema permite gestionar notas mediante lógica pura en código (sin interfaz gráfica). Está enfocado en reforzar conceptos fundamentales de JavaScript como:

- Manipulación de arrays
- Uso de objetos
- Métodos de iteración
- Modularización de funciones
- Buenas prácticas de estructura y organización del código

## ⚙️ Funcionalidades

- ✅ Crear notas
- ✏️ Editar notas
- ❌ Eliminar notas

## 🧠 Objetivo del Proyecto

Practicar la lógica de programación y fortalecer habilidades en JavaScript mediante la construcción de un pequeño sistema tipo CRUD desde cero.

## 🚀 Tecnologías utilizadas

- JavaScript (ES6+)
